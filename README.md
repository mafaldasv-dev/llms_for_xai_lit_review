# llms_for_xai_lit_review

## Project Overview
This repository contains code and resources used for a scoping review on the use of Large Language Models (LLMs) for Explainable Artificial Intelligence (XAI). It includes scripts and notebooks for literature search, data processing, and analysis.

## Installation
1. Install [uv](https://github.com/astral-sh/uv):
   ```bash
   pip install uv
   ```
2. Create a virtual environment:
   ```bash
   uv venv .venv
   ```
3. Install dependencies:
   ```bash
   uv pip install -r requirements.txt
   ```
4. Activate the environment:
   ```bash
   source .venv/bin/activate
   ```

## Usage
- Jupyter notebooks for exploration and documentation are in the `notebooks/` folder.
- Python scripts for data processing and analysis are in the `scripts/` folder.
- Archived notebooks are in `old_notebooks/`.
- Place datasets in the `data/` folder.
